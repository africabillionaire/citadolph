# Easter Egg & Delight Details

Load when adding hidden details, playful moments, personality, or delight.

---

## Rules

### easter-egg-1 — Delight must be skippable
Any playful animation, sound, or interaction must be dismissible or naturally time-bound. The user should never be trapped in a "delightful" moment when trying to complete a task.

### easter-egg-2 — Frequency gates
A detail that fires every time quickly becomes noise. Limit easter eggs to: first visit, first completion of a milestone, or random occurrence (`< 10%` chance). Never show the same playful animation on every page load.

### easter-egg-3 — No sound without consent
Never autoplay sound for delight. If sound is part of the experience, require an explicit opt-in or tie it to a user-initiated action where audio is expected.

### easter-egg-4 — Personality in error states
Error pages (404, 500, offline) are the best place for personality — the user is already frustrated, and a human touch reduces stress. Keep it brief: one line of empathy, one helpful action, one small visual moment.

### easter-egg-5 — Konami-code tier
Advanced easter eggs (Konami codes, hidden clicks, secret key combos) are fine for power users but must never be the only path to a feature. They are rewards, not interfaces.

### easter-egg-6 — Seasonal restraint
Holiday themes and seasonal decorations should be subtle (favicon change, minor accent color shift) and automatically expire. A Santa hat on the logo in February is a detail that aged badly.

### easter-egg-7 — Microcopy personality
Button labels, empty states, and success messages can carry voice. "Boom, you're in!" on a signup success is fine for a consumer app; "Account provisioned successfully" is appropriate for enterprise. Match the voice to the context.

### easter-egg-8 — Cursor details
Custom cursors are acceptable only for specific modes (drawing tools, drag handles, zoom lenses). Never replace the default cursor globally — it breaks user trust in the system's affordances.

### easter-egg-9 — Celebration timing
Celebrate user achievements (first post, 100th save, streak milestone) with a brief, non-blocking animation (`< 2s`). Provide a "Don't show again" option. The celebration should not block the next action.

### easter-egg-10 — Brand mascot restraint
If using a mascot or character, it should appear only in onboarding, empty states, and error states — never in the critical path. The user should be able to complete every primary task without interacting with the mascot.
